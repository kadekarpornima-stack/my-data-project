# My Data Project Cheat Sheet

## 1. Starting a Session (Every time I open VS Code)
Always make sure the environment is active:
`.\env\Scripts\Activate.ps1`

## 2. Saving to GitHub (The "Big Three" Loop)
Run these whenever I finish a piece of work:
1. `git add .` (Gather files)
2. `git commit -m "Describe what I did"` (Save snapshot)
3. `git push` (Upload to GitHub)

## 3. Installing New Tools
If I ever need a new library later:
1. `pip install library-name`
2. `pip freeze > requirements.txt` (Update shopping list)
